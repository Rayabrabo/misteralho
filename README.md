# Cardápio digital — Mister Alho

Cardápio de consulta (sem pedidos online). Pedidos somente no balcão.

## Abrir no computador
Dê dois cliques em `index.html`.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub e envie todo o conteúdo desta pasta (mantendo `css`, `js` e `img`).
2. Em Settings > Pages, escolha a branch `main` e a pasta `/ (root)`.
3. O site ficará em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Editar
- Produtos e preços: `js/app.js` (lista `P`).
- Cores e layout: `css/style.css`.
- Imagens: pasta `img`.
